## Alpha67 — Personal holding colors

Choose from nine colors in CHARACTER → HOLDING COLOR → SAVE CHARACTER. The holder's chosen outline is visible to other players. Each character saves its own selection; existing profiles default to green.

Includes the accumulated co-op features and fixes through Alpha67.

### Install

Download **PITT-Co-op-Alpha67-Mod-Only.zip**, extract it into your own Windows Project P.I.T.T. **1.0.8** game folder, run **Install Mod.cmd**, then **Play Co-op.vbs**. Python 3 is required for installation. Both players must use Alpha67.

This is an experimental unofficial mod. No game files are included. See the repository README for hosting, joining, controls and limitations.
